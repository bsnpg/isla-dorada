Isla Dorada: 8 Jobs to Clear His Name — a GTA-style 3D open-world crime game for make.fun gta6-01. Wowo, ex-Sergeant, dishonourably discharged, came to Isla Dorada to disappear and became its most wanted getaway driver. Eight jobs stand between him and a clean name: drive the Aurea GT, fight the IDPD, fly the jetpack, raid the warehouse and escape the island.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD drive & walk · mouse aim · 1–6 switch weapons · Q weapon wheel · J jetpack · E steal car · M map · Esc pause.
